# AI Fight Arena (สนามแข่งกลาง Ikemen GO)

เว็บเซิร์ฟเวอร์สำหรับจัดการแข่งต่อสู้: คนสมัครด้วยชื่อตัวเอง + เลือกตัวละครที่มีอยู่ (หรืออัปโหลดตัวเอง) แล้ว **แอดมินเป็นคนเลือกว่าใครแข่งกับใคร** ทุกแมตช์รันบนเครื่องกลางเครื่องเดียว
ใช้ Ikemen GO ชุดเดียวกัน ด่านเดียวกัน กติกาเดียวกัน พร้อม **ถ่ายทอดสดผ่านหน้าเว็บ** ให้เพื่อนเปิดดูได้จากมือถือหรือคอมเครื่องอื่นในวงแลน

```
สมัคร (ชื่อ + เลือก/อัปโหลดตัวละคร) → [ตัวใหม่: ตรวจไฟล์ + เทสโหลด] → แอดมินเลือกคู่ กด “แข่งเลย” → คิว → ตารางคะแนน + Elo
                                                         └→ ภาพสด (MJPEG) + หลอดเลือดสด (SSE)
```

## ตั้งเครื่องกลาง (เครื่องไหนในทีมก็ได้)
ต้องมี: **Windows** (ใช้จับภาพหน้าต่างเกมกับคุมคีย์บอร์ด), **Python 3** (ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH"), **RAM ว่าง 2 GB ขึ้นไป**
ส่วน Ikemen GO อยู่ใน repo แล้ว (โฟลเดอร์ `ikemen/`) ไม่ต้องหาเพิ่ม

```
git clone https://github.com/PeemPasae/ai-fight-arena.git
cd ai-fight-arena
start.bat                  # ลงแพ็กเกจ (requirements.txt) แล้วเปิดเซิร์ฟเวอร์ ดับเบิลคลิกก็ได้
```
- เปิดครั้งแรก ระบบจะสร้าง `engine/` จาก `ikemen/` ให้เอง
- หน้าต่างจะแสดงลิงก์ให้เพื่อน (เช่น `http://192.168.x.x:8080`) และ **รหัสแอดมิน** (อยู่ใน `data/admin_token.txt` ห้ามแชร์)
- Windows Firewall จะถามตอนเปิดครั้งแรก ให้กด Allow
  - ถ้าไวไฟตั้งเป็น Public เพื่อนจะเข้าไม่ได้ ต้องตั้งเป็น Private ชั่วคราว เลิกใช้แล้วเปลี่ยนกลับเป็น Public
- จะรับไฟล์ .rar ได้ต้องลง WinRAR ไว้ด้วย (`UNRAR` ใน `arena/config.py`) ถ้าไม่มี ก็รับได้แค่ .zip
- **ระหว่างแมตช์ห้ามใช้เครื่องนี้** หน้าต่างเกมจะเด้งขึ้นมา และบอทกดคีย์บอร์ดจริง

### ย้ายสนามจากเครื่องเดิมไปเครื่องใหม่ (ตัวละคร ผู้เล่น ผลแข่ง)
```
# เครื่องเดิม (ปิดเซิร์ฟเวอร์ก่อน)
python tools\move_arena.py export arena_bundle.zip
# เครื่องใหม่ (หลัง git clone และยังไม่ได้เปิดเซิร์ฟเวอร์)
python tools\move_arena.py import arena_bundle.zip
start.bat
```
- ไฟล์ bundle มีชื่อเพื่อนและตัวละครที่อัปโหลด ส่งกันทาง USB หรือลิงก์ Drive แบบส่วนตัว **ห้ามใส่ใน git**
- สิ่งที่ไม่ได้ย้ายไปด้วย:
  - รหัสแอดมิน (เครื่องใหม่สร้างใหม่ให้เอง)
  - log ต่าง ๆ
  - บอทที่อยู่นอกโฟลเดอร์สนาม เช่น บอทส่วนตัวของภีม (ผู้เล่นคนนั้นจะสู้ด้วย AI ของเกมแทน)

คำสั่งอื่น:
| คำสั่ง | ทำอะไร |
|---|---|
| `python arena.py setup` | สร้าง/รีเซ็ตเกมชุดกลาง `engine/` ใหม่จาก `ikemen/` (ไม่ลบข้อมูล) |
| `python arena.py add-char <โฟลเดอร์ตัวละคร>` | เพิ่มตัวละครเข้า roster ให้คนเลือก |
| `python arena.py add-player --name <ชื่อ> --char c001 --bot <bot.py> --reserve` | เพิ่มผู้เล่นจากเครื่องนี้ (บอทอนุมัติอัตโนมัติ, `--reserve` = คนอื่นเลือกตัวนี้ไม่ได้) |
| `python arena.py list` | ดูตัวละครและผู้เล่น |

## หน้าเว็บ
| แท็บ | สำหรับ |
|---|---|
| ถ่ายทอดสด | ภาพจากเกมสด ๆ + หลอดเลือด/พลัง/ยกที่ชนะ + คิวถัดไป + ผลล่าสุด |
| ตารางคะแนน | ต่อผู้เล่น: ชนะ 3 / เสมอ 1 แต้ม → ผลต่างยก → ผลต่าง % เลือด → Elo + ฟอร์ม 5 นัดล่าสุด |
| ผลแมตช์ | ทุกแมตช์ กดดูรายละเอียดรายยก + กราฟ % เลือดตลอดแมตช์ |
| ผู้เล่น | ใครใช้ตัวอะไร สถิติ ชนะ/เสมอ/แพ้ |
| ตัวละคร | roster ทั้งหมด ใครใช้อยู่ ตัวไหนจองแล้ว |
| ข้อมูลฝึกบอท | ดาวน์โหลดรายการ state ของทุกตัว (.md/.csv/.json สร้างอัตโนมัติจากไฟล์ตัวละคร) + log แมตช์ทุกเฟรม (.jsonl.gz) แยกตัว หรือทั้งหมดใน zip เดียว พร้อม README อธิบายฟิลด์ |
| สมัครเข้าแข่ง | ใส่ชื่อ → เลือกตัวที่มีอยู่ หรืออัปโหลด .zip/.rar ของตัวเอง (ตัวที่อัปโหลดเข้า roster ให้คนอื่นเลือกได้ด้วย) + บอท (ไม่บังคับ) |
| แอดมิน | **จัดแมตช์** (เลือก P1/P2 จำนวนแมตช์ สลับฝั่ง → แข่งเลย), ดู/ยกเลิกคิว, แข่งซ้ำ, หยุดแมตช์, อนุมัติบอท, พัก/ลบผู้เล่น, เทสใหม่/ลบตัวละคร |

## กติกา (ปรับได้ใน `arena/config.py` หรือ `data/settings.json`)
- แอดมินเลือกคู่เอง แมตช์เข้าคิวและแข่งตามลำดับ · ชนะ 2 ยกก่อนชนะแมตช์ (`ROUNDS`) · ด่าน `stages/kfm.def`
- ชื่อผู้เล่นห้ามซ้ำ · หลายคนเลือกตัวละครเดียวกันได้ (ยกเว้นตัวที่จองไว้)
- ไม่ส่งบอท → ตัวละครเล่นด้วย AI ของเกม level 8 (`AI_LEVEL`) ซึ่งใช้ AI ในตัวละครถ้ามี
- แมตช์ที่ผลไม่นับ (เกินเวลา / หน้าต่างหลุดโฟกัส) จะถูกแข่งใหม่อัตโนมัติสูงสุด 3 ครั้ง · แมตช์ที่แอดมินกดหยุด = ยกเลิก
- ตัวละครใหม่ต้องผ่าน **เทสโหลด** (สู้กับ kfm ภายใน ~60 วินาที ไม่ตกเพราะ intro ยาว/โหลดช้า ตกเฉพาะเกม crash หรือไม่เริ่มแมตช์เลย) ถึงจะใช้แข่งได้ · ถ้าตก เหตุผลจาก log ของเกม (เช่น `Invalid data: ...`) จะขึ้นในแท็บตัวละคร

## ข้อกำหนดไฟล์ตัวละคร (ส่งให้เพื่อนอ่านก่อนส่ง)
- `.zip` หรือ `.rar` เท่านั้น ไม่รับ `.7z` ห้ามตั้งรหัสผ่าน · 1 ไฟล์ = 1 ตัวละคร · ไม่เกิน 150 MB
- ต้องมี `.def` ที่มี `[Info]` + `[Files]` และไฟล์ที่อ้างถึง (sff, air, cmd, cns/st) อยู่ครบ ชื่อตรงกัน
- ห้ามมี `.exe/.dll/.bat` (ลบตัวติดตั้ง/โปรแกรมที่ติดมาออก)
- ต้องรันบน Ikemen GO ได้ (ตัว MUGEN 1.0/1.1 ผ่านง่ายสุด) · ควรมี AI ในตัว · ห้ามตัวโกง/ตัวบั๊ก
- ระบบแก้ให้อัตโนมัติ: เว้นวรรคแบบญี่ปุ่น (U+3000) ในไฟล์โค้ดของตัว WinMUGEN เก่า ซึ่งทำให้ Ikemen ปิดตัวด้วย `Invalid data`
- ส่งไฟล์ที่เหมือนกับที่มีอยู่แล้วทุกไบต์ = ใช้ตัวละครเดิม ไม่เก็บซ้ำ · หลังติดตั้งจะเก็บแค่ไฟล์ต้นฉบับใน submissions/ (ไม่เก็บชุดที่แตกแล้ว) · ถ้าไดรฟ์เหลือต่ำกว่า 5 GB (`MIN_FREE_GB`) จะหยุดรับอัปโหลด
- การสมัครที่ถูกปฏิเสธจะถูกจดใน `data/rejections.jsonl` และดูได้ในหน้าแอดมิน

## ส่งบอท (ไม่บังคับ)
zip ที่มี `bot.py` อยู่ชั้นนอกสุด เซิร์ฟเวอร์จะรัน:
```
python bot.py --player 1|2 --game-dir <AI_Fight_Arena\engine>
```
- อ่านสถานะทุกเฟรมจาก `<game-dir>\general_bot_telemetry.json` (`p1`/`p2`: hp, power, state_no, ctrl, move_type, body_dist_x, in_guard_dist, …)
- กดปุ่มด้วยคีย์บอร์ดตามปุ่มของ P1/P2 ใน `<game-dir>\save\config.ini` (ดูตัวอย่างใน `..\bot\ikemen_io.py`)

## ความปลอดภัย (อ่านก่อนเปิดให้คนอื่นส่ง)
- **ไฟล์ตัวละคร** เป็นข้อมูล (.def/.cns/.air/.sff/.snd) ระบบกันไว้แล้ว: บล็อก .exe/.dll/.bat ฯลฯ, กัน zip ที่พยายามเขียนออกนอกโฟลเดอร์, จำกัดขนาด/จำนวนไฟล์, ตรวจว่า .def อ้างไฟล์ครบ
- **บอทคือโค้ด Python ที่รันบนเครื่องนี้ด้วยสิทธิ์ของคุณ** — ระบบจะไม่รันจนกว่าแอดมินกดอนุมัติ
  **อ่านโค้ดใน `submissions/<id ผู้เล่น>/bot/` ก่อนอนุมัติทุกครั้ง** และอนุมัติเฉพาะคนที่ไว้ใจ ถ้าจะเปิดรับจากคนไม่รู้จัก ควรย้ายเซิร์ฟเวอร์ไปรันใน VM ที่ไม่มีข้อมูลส่วนตัว
- เซิร์ฟเวอร์เปิดให้ทุกเครื่องในวงแลนเดียวกันเข้าได้ (`HOST = 0.0.0.0`) ถ้าอยากให้เฉพาะเครื่องนี้ ตั้ง `HOST = "127.0.0.1"`
- ไม่มีระบบบัญชีผู้ใช้: ใครเข้าเว็บได้ก็ส่งไฟล์ได้ (จำกัด 1 ครั้ง/20 วินาที/IP) แอดมินลบรายการที่ไม่ต้องการได้

## ข้อจำกัด
- แมตช์ที่มีบอทกดคีย์บอร์ดจริง: **ระหว่างแข่งห้ามใช้เครื่องเซิร์ฟเวอร์** ถ้าหน้าต่างเกมหลุดโฟกัสเกิน 2 วินาที แมตช์นั้นไม่นับและจะแข่งใหม่
- แข่งได้ทีละแมตช์ (เครื่องเดียว) ~1.5–5 นาที/แมตช์
- ภาพสดจับจากหน้าจอ ถ้ามีหน้าต่างอื่นบังเกม ภาพจะติดหน้าต่างนั้นไปด้วย

## โครงสร้างโฟลเดอร์
```
arena.py            จุดเริ่มโปรแกรม
arena/config.py     ค่าตั้งทั้งหมด
arena/engine.py     สร้างเกมชุดกลาง, รันแมตช์, เทสโหลด
arena/worker.py     เธรดที่คุมคิวแข่ง
arena/league.py     สร้างแมตช์ (แอดมินเลือกคู่), ลำดับคิว, คะแนน, Elo
arena/submissions.py  รับไฟล์ + ตรวจความปลอดภัย
arena/capture.py    จับภาพหน้าต่างเกมเป็นวิดีโอสด
arena/web.py        เว็บเซิร์ฟเวอร์ + API
web/                หน้าเว็บ (index.html, app.js, style.css)
engine/             Ikemen GO ชุดกลาง (สร้างอัตโนมัติ) — chars/<id>/ = ตัวละครใน roster
submissions/c###/   ตัวละครที่อัปโหลด (ต้นฉบับ + ที่แตกแล้ว) · submissions/p###/bot/ บอทของผู้เล่น
data/arena.json     ฐานข้อมูล ตัวละคร (chars) / ผู้เล่น (players) / แมตช์ · data/traces/ log ทุกเฟรมของแต่ละแมตช์ (gzip)
arena/stateindex.py  สร้างรายการ state จากไฟล์ตัวละคร · arena/exports.py  แพ็กไฟล์ดาวน์โหลด · data/matches/ กราฟเลือด · data/logs/ log เกมและบอท
```
